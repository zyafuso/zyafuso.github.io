def convolve2d_naive(image, kernel):
    H, W = image.shape
    kH, kW = kernel.shape
    pad_h, pad_w = kH // 2, kW // 2
    padded = np.pad(image, ((pad_h, pad_h), (pad_w, pad_w)), mode='constant')
    output = np.zeros_like(image)
    for i in range(H):
        for j in range(W):
            entry = 0
            for k in range(kH):
                for l in range(kW):
                    entry += padded[i+k, j+l] * kernel[k, l]
            output[i, j] = entry
    return output
def convolve2d_fast(image, kernel):
    H, W = image.shape
    kH, kW = kernel.shape
    pad_h, pad_w = kH // 2, kW // 2
    padded = np.pad(image, ((pad_h, pad_h), (pad_w, pad_w)), mode='constant')
    output = np.zeros_like(image)
    for i in range(H):
        for j in range(W):
            region = padded[i:i+kH, j:j+kW]
            output[i, j] = np.sum(region * kernel)
    return output

Box Filter Application

Above are some basic implementations of convolution, a standard process in image processing. Below are some examples of what convolution can be used for. In short, convolution multiplies a kernel or small array to sections of an image. Every pixel after a convolution is a representation of the data produced by this kernel image multiplication. For my convolutions, boundaries are zero-padded which will induce a vignette look to the edges. For the Scipy convolution function I used the symmetric boundaries which gives much cleaner edges because it is not convolving with the zero padding.

If you look closely at the two convolutions below, one has a uniform dark edge while the other does not.

A gradient magnitude displays both the vertical and horizontal edges in an image. Edge detection can be useful for sensing, but these gradient magnitude images have too much noise. There is no way to pick out an edge from a blade of grass in this filtered image. To fix this, we set a flat intensity filter to eliminate noise pass everything else. We have created a binarized edge map.



One way to achieve the gradient magnitude is to first blur with the gaussian and then apply the finite difference operators. Somewhat unsurprisingly, you end with the same result if you convolve the directional derivative of gaussians instead.

Part 2.1: Image "Sharpening"

Sharpening images once we have a gaussian filter is easy. The gaussian takes the low frequencies of an image. So after subtracting out the gaussian, we are left with high frequencies. This can be added back for a boosted high frequency and "sharper" image.

Sharpening Blurry Images

When we sharpen images, alpha is the value that will scale the high frequencies we are adding back to the image.

Part 2.2: Hybrid Images

The images shown below are hybrid images created by blending low and high frequencies of similar images. High frequencies contain detail and will be apparent but when you blur you vision or look from further away, high frequencies tend to be harder to recognize and the low frequencies will become clearer. The idea behind these hybrids is exactly this.

For the best results when creating these hybrid images, the low frequency image should have a strong shape and outline while the high frequency image should contain fine details. A good example of this is Derek and Nutmeg. Nutmegs fur and expressions show up through Derek's outline because the higher frequencies contain the detail of Nutmeg.

Part 2.3: Multiresolution Blending

Gaussian stacks are stages of frequencies obtained by applying a stronger gaussian at each stage. Laplacian stacks are band passes of frequencies that can be obtained by finding the differences between stages of a gaussian stack. These blends explore how to use these image stacks to create a cleaner hybrid.

Laplacian Stacks Comparison

This is a visual representation of what a Laplacian stack looks like. Each level represents a band pass of frequencies with level 3 being the last level containing every low frequency left. By applying the gaussian stack of masks to these images each band of frequency is blended differently. Coarse(low) frequencies have a gradual blend and fine details or high frequencies have a more abrupt cutoff. This technique is known as a spline.
