Autostitching and Photomosaics

This project focuses on creating an autostitching algorithm to automatically stitch together larger mosaic images. The goal is to develop a robust system that can identify corresponding points between images, compute homography transformations, and seamlessly blend multiple photographs into panoramic views.

Technical Implementation

Homography Computation

Using the eight-point algorithm to compute homography matrices that map corresponding points between images. This allows for perspective correction and proper alignment of overlapping regions.

Image Warping

Implementing nearest neighbor interpolation to warp images according to computed homography transformations, ensuring proper geometric alignment before blending.

Automatic Feature Detection

Developing algorithms to automatically detect and match corresponding features between images, eliminating the need for manual point selection in the stitching process.

def computeH(im1_pts, im2_pts):
    """
    Compute the homography matrix H using the eight-point algorithm.
    lambda_im2_pts = H * im1_pts
    """
    for i in range(len(im1_pts)):
        x = im1_pts[i][0]
        y = im1_pts[i][1]
        u = im2_pts[i][0]
        v = im2_pts[i][1]
        if i == 0:
            X = np.array([[x, y, 1, 0, 0, 0, -x*u, -y*u],
                    [0, 0, 0, x, y, 1, -x*v, -y*v]])
            b = np.array([u, v])
        else:
            A = np.array([[x, y, 1, 0, 0, 0, -x*u, -y*u],
                    [0, 0, 0, x, y, 1, -x*v, -y*v]])
            X = np.vstack([X, A])
            b = np.vstack([b, np.array([u, v])])
    H = np.linalg.inv(X) @ b
    H = H.reshape(3,3)
    H[2,2] = 1
    return H
def warpImageNearestNeighbor(im, H):
    """
    Warp image using homography matrix H with nearest neighbor interpolation
    """
    H_inv = np.linalg.inv(H)
    h, w = im.shape[:2]

    # Find bounding box of warped image
    corners = np.array([[0,0,1], [w-1,0,1], [0,h-1,1], [w-1,h-1,1]]).T
    warped_corners = H @ corners
    warped_corners /= warped_corners[2]  # normalize
    
    x_min = np.min(warped_corners[0])
    x_max = np.max(warped_corners[0])
    y_min = np.min(warped_corners[1])
    y_max = np.max(warped_corners[1])

Key Algorithm Components

Homography Computation: The eight-point algorithm constructs a system of linear equations to solve for the 3x3 homography matrix that maps corresponding points between images.

Image Warping: Using the computed homography, images are transformed to align with a common coordinate system, enabling seamless blending of overlapping regions.

Feature Matching: Automatic detection and matching of corresponding features eliminates manual intervention and enables robust panoramic creation from arbitrary image sequences.

Challenges and Solutions

Perspective Distortion

Different camera positions create varying perspectives that must be corrected through homography transformations to ensure geometric consistency in the final panorama.

Lighting Variations

Changes in lighting conditions between images require careful blending techniques to maintain visual continuity and avoid noticeable seams in the final result.

Feature Detection

Robust feature detection algorithms must identify distinctive points that remain consistent across different viewing angles and lighting conditions.

Applications and Future Work

Autostitching algorithms have numerous applications in photography, virtual reality, and computer vision:

Future enhancements could include real-time stitching capabilities, improved handling of moving objects, and integration with machine learning for better feature detection and matching.
