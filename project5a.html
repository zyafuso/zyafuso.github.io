1.2 Classical Denoising (Gaussian Blur)

1.4 Iterative Denoising (Strided Timesteps)

When adding noise to the campanile image, there are actually 1000 timesteps t. So using our previous denoiser, we could run the Unet through 1000 steps of denoising. However, this would be slow and expensive, so instead we will take strided timesteps using the principle that noise can be represented as a continuous time function and therefore differentiated. In the images below, I take about ~30 total steps through the image space. The Unet can be thought of as iteratively stepping, or walking, the noise towards the real image manifold.

The stage 2 images were enhanced for a better view of each of the various methods explored in the previous parts next to the final result of our iterative denoising.

1.6 Classifier-Free Guidance Sampling

In this step, we will use a strong diffusion model optimization that splits the model attention and training into two parts. One part focuses on answering the question of, “If I ignore the prompt, what clean image would explain this noisy image?” The other part focuses on explaining the noisy image with the prompt. With the expense of image diversity, we greatly improve overall image quality.

For the above 5 images, I took a random set of 5 that were generated. They happened to contain mostly people, so I included them but many images also contained animals, structures, landscapes, etc.
